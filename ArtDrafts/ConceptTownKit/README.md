# Объекты по утверждённому концепту

Генератор создаёт 12 визуальных моделей в изолированной копии Unity. Результат выдаётся в `ArtDrafts/ConceptTownKit`, вне `Assets`: игровые сцены и существующий TownKit не обновляются.

Исходники используют геометрические инструменты существующего TownKit. `ConceptBuildings` отвечает за городские здания, `ConceptInfrastructure` — за транспорт и стройку, `ConceptFarm` — за сельское хозяйство. Общие архитектурные детали находятся в `ConceptParts`. `ConceptGeneration` сохраняет и проверяет модели, материалы, OBJ и реальные рендеры Unity.

Запуск из PowerShell 7: `./Scripts/GenerateConceptTownKit.ps1`.

Это статические модели окружения, без интерьеров, коллайдеров и игровых обработчиков. Стёкла остановки и теплицы имеют отдельный прозрачный материал. Одна единица — один метр, вертикаль +Y, фасад +Z. Основание каждого объекта лежит на Y=0.

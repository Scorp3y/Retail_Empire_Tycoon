# Выкладка товаров

В префабах стеллажей настроены `ShelfProductDisplay` и дочерние точки
`ProductSlots/Slot_*`. При переносе товара со склада `PlacedShelfStock`
сообщает об изменении запаса, а `ShelfProductDisplay` обновляет модели.
В `ProductItemData.ShelfDisplayPrefab` назначен существующий префаб товара.
Сохранения используют прежние идентификаторы товаров и стеллажей.

| Стеллаж | Товар | Точек |
| --- | --- | --- |
| Fresh Market Shelf | Bread | 20, исходная настройка |
| Double-Sided Shelf | SodaCola | 132 |
| Wall Goods Shelf | Oil | 72 |
| Cold Pantry | Steak | 42 |
| Refrigerated Display | MilkBottle | 168 |

Координаты измерены в локальной системе стеллажей по импортированным mesh.
У колы учтён центрированный pivot. Крышки-рамки `freezer.001` сохранены;
мясо размещено внутри на двух поддонах (поверхность y=0.258), ниже крышек.
Поддоны приподнимают глубокое дно, чтобы борта не скрывали весь товар.
Товары выложены плотными рядами с небольшим зазором без пересечений.
У колы по три ряда с каждой стороны, у масла и молока по три ряда в глубину.
По ширине у колы 11 бутылок, у молока 7 упаковок в каждом отделении.
В каждом мясном лотке 3 колонки и 7 рядов вдоль поддона.
Вместимость соответствует числу точек. Старые сохранённые количества не
увеличиваются автоматически: для заполнения новых рядов нужно догрузить товар.
Масштаб молока учитывает расстояние между полками и центральную стойку.

## Повторная настройка

Меню Unity `Retail Empire > Products > Configure shelf displays` повторно
настраивает четыре новых стеллажа. Оно **заменяет их точки ProductSlots**
на координаты из `ShelfStockSetup.cs`: ручную расстановку внутри этой группы
перед запуском нужно сохранить отдельно. Хлебную полку меню не изменяет.
Обычный импорт проекта и запуск игры эту настройку не выполняют.

## Проверка

`ShelfStockValidation.RunBatch` запускается отдельным Unity-процессом
с аргументами `-batchmode -projectPath <путь проекта> -executeMethod
RetailEmpireTycoon.EditorTools.ShelfStockValidation.RunBatch -logFile <лог>`.
Не добавлять `-quit`: проверка сама завершает Unity с кодом 0 или 1.
Основной редактор должен освободить проект перед пакетным запуском.

В открытом редакторе доступно меню `Retail Empire > Products > Validate
shelf displays`. Проверка требует одной сохранённой сцены в Edit Mode.
Она временно открывает тестовую сцену, запускает Play Mode и по окончании
возвращает исходную сцену. Пользовательское сохранение игры не изменяется.

Проверка использует временную несохранённую сцену в Play Mode: перенос одного
товара и полного запаса, остаток на складе, отклонение несовместимого товара,
взятие товара, очистку и восстановление склада и полок через JSON и
`ProductSaveService`. Она проверяет число видимых моделей и их пересечения,
создаёт изображения единичной и полной выкладки в `Library/ShelfStockQA`.
Результат находится в `Library/ShelfStockQA/validation.txt`.
Пользовательский `gameData.json` проверка не читает и не изменяет.

Проверка подсветки дополнительно сравнивает концы всех 12 цилиндров с углами
рамки: на исходных префабах, при масштабе 0.17, поворотах и неравномерном
масштабировании. Шарики на углах не создаются. Проверяется плотность рядов
и наличие крышек. Превью подсветки имеют суффикс `_highlight.png`.

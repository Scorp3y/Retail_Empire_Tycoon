# Камера и предпросмотр строительства

Первый этап: WASD/стрелки, Shift для ускорения, колёсико к курсору,
зажатая ПКМ для перемещения, средняя кнопка для вращения и наклона.
V переключает верхний ракурс, Home возвращает исходный обзор.
Модальные окна и режим покупки территории по-прежнему отключают MainCamera.
При включении камера считывает текущую позу, поэтому не прыгает обратно.

Строительство: ЛКМ ставит объект или красит пол, R/E поворачивает на 90°,
Q поворачивает обратно, Esc отменяет размещение. Короткий ПКМ вне строительства
показывает информацию о стеллаже; перемещение ПКМ её не открывает.
Загрузка товара выполняется ЛКМ: ПКМ больше не загружает товар при движении камеры.

Путь данных: курсор → пересечение с плоскостью GridSystem → клетка →
BuildController.CanPlaceAt → существующие правила размещения и проверка склада →
BuildPreview (цвет, занимаемые клетки, причина) или TryPlaceAt (установка).
Недопустимая попытка не расходует запас. Установка списывает один предмет.
После установки предмет остаётся выбранным, пока запас не закончится.

Предпросмотр копирует только MeshFilter/MeshRenderer и трансформы текущих
статических моделей. Он не содержит игровых скриптов, коллайдеров или сохранений.
Анимированные SkinnedMeshRenderer в этом этапе не поддерживаются.
Материалы предпросмотра — прозрачные URP Unlit, HUD — обычный Canvas/Text,
не перехватывающий клики. Формат сохранения не изменён.

Обновление: нижний HUD удалён. Сетка чёрная без зелёной заливки, её высота
0.11 над логической плоскостью (внутренний пол меша магазина — 0.096).
Клавиатурное перемещение ускорено ровно втрое относительно прежних настроек.
Размеры восьми строительных моделей измерены по мешам без EmptyProductMarker;
BuildPlacementPose центрирует модель в её клетках без изменения масштаба.
Одинаковая позиция используется в предпросмотре, установке и загрузке.
Передняя сторона текущих односторонних стеллажей — +Z; двусторонний требует
свободного подхода с +Z и -Z. Проверка учитывает поворот и pivotOffset.
Загрузка старых объектов использует исправленное выравнивание и новые размеры;
ручные объекты сцены без строительных данных автоматически не переставляются.

StoreWallOccluder явно помечает стены двух строительных prefab. В строительстве
StoreWallVisibility скрывает обращённые к камере стены перед точкой обзора,
сохраняя коллайдеры и исходное состояние рендереров. После выхода стены возвращаются.
Это геометрическая отсечка, не полный поиск закрывающих объектов по каждому пикселю.

Команды Retail Empire > Building:
- Configure camera and placement применяет материалы и ссылки к сохранённой Game.
- Validate camera and placement проверяет поведение в временной дополнительной сцене.
- Open isolated sandbox создаёт отдельную сцену без экономики и сохранения игрока;
  в Play Mode Begin sandbox placement даёт тестовый запас. После проверки остановить
  Play Mode и выбрать Return to Game scene.

Отчёты: Library/CameraBuildQA. Перенос уже установленных объектов, undo и полный
поиск маршрутов покупателей не входят в этот этап. Ограждения территорий не изменены.

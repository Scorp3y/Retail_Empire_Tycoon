# Интерфейс магазина

## Визуальное направление

Спокойный low-poly супермаркет: кремовые поверхности, лесной зелёный текст,
свежий зелёный для основного действия, золото для стоимости и рейтинга.
Большая ярко-салатовая заливка и толстая белая рамка заменены тонкой границей.
Панели магазина и инвентаря стоят справа; мир остаётся видимым слева.
Затемнение используется только для подтверждений и настройки клавиш.

Цвета определены в `ShopUiTheme`: Paper #F5F1E5, Ink #203E32,
Green #79BB43. Не задавайте отдельную палитру для следующего окна.
Шрифт — Rubik Regular для текста и Rubik Medium для заголовков.
Нативное начертание Medium используется вместо искусственно утолщённых букв.
Русский и английский поддерживаются; заголовки больше не написаны сплошным капсом.

## Что обновлено

- HUD: баланс слева сверху, пять существующих звёзд по центру,
  квадратные замок/территории/настройки справа сверху, магазин/склад справа снизу.
  Уровень магазина и нижние объявления об открытии скрыты.
  Подсказки клавиш слева — только текст с мягкой тенью.
- Магазин: оборудование, товары, персонал. У оборудования две категории:
  полки и структуры; касса находится в структурах. Каталог прокручивается
  вертикально, переход к другой категории возвращает его к началу.
- Инвентарь и склад: тот же язык карточек, количество и существующие действия
  установки/выкладки. Недоступная покупка отражается состоянием кнопки.
- Персонал: четыре профессии, фактические лимиты, стоимость найма и зарплата.
  Это страница магазина, а не отдельная вкладка среди структур.
- Настройки: громкость музыки и эффектов, язык, управление, сохранение,
  подтверждение перехода в меню/выхода. Назначение клавиш сохраняет прежние правила.
- Мини-игры: компактная нижняя панель действия и прогресса.
  Информация о полке удерживается внутри экрана даже при клике у края.
- На коротком широком экране `ShopPanelFit` масштабирует всё окно,
  а не обрезает его фон вместе с нижними кнопками.

## Границы и путь данных

`ShopUiTheme` — ресурсы и цвета; `ShopUi` — создание элементов;
`ShopWindowNavigation` — выбранные вкладки; `ShopHudPresenter` — краевой HUD;
`ShopSettingsPanel` — связь настроек с существующими контроллерами.
`ShopUiSetup` — явная, повторяемая миграция сцены и четырёх префабов карточек.
Миграция не запускается автоматически при импорте.

Покупка: кнопка карточки → существующий `MoneyController.TrySpend` →
строительный инвентарь или склад → события изменения → обновление UI.
Баланс после загрузки приходит из того же кошелька, а не из отдельной UI-копии.
ID предметов, формат сохранений и правила экономики не менялись ради оформления.
Найм передаётся существующему списку работников; интерфейс не рассчитывает лимиты сам.
Рабочая панель показывает состояние `WorkMinigame`, не списывая товары самостоятельно.

## Арт и лицензии

Навигационные символы построены `ShopIconGraphic` из простых масштабируемых
силуэтов. Превью оборудования и продукции в `Assets/Art/ShopUi/Items`
рендерятся из настоящих моделей через `ShopUiPreviews`, поэтому соответствуют миру.
Плитка пола без модельного префаба сохраняет существующую иконку.

Один новый портрет сотрудника создан встроенным ImageGen с прозрачным фоном
и скопирован без изменения альфа-канала в
`Assets/Art/ShopUi/EmployeePortrait.png`.
Краткое содержание промпта: дружелюбный low-poly сотрудник супермаркета,
портрет по грудь, зелёная кепка и фартук, кремовая рубашка, простые гранёные
формы, мягкий свет, прозрачный фон, без текста и логотипов.
Портрет общий для профессий; роль различается отдельным значком.

Rubik взят из официального [репозитория Google Fonts](https://github.com/googlefonts/rubik).
Исходники Regular/Medium и лицензия SIL OFL лежат в `Assets/Art/ShopUi/Fonts`.
Рабочие TMP-ресурсы — `Assets/Resources/ShopUi/RubikRegular.asset`
и `RubikMedium.asset`; назначение хранит `Theme.asset`.

## Проверка

В Unity 2022.3.62f3 проверки выполнялись в `ShopGameplaySandbox` без
`SaveManager`. Планировка игрока загружалась только для чтения.
Кнопка сохранения подключена к прежнему обработчику, но намеренно
не нажималась на пользовательском сохранении.

Пройдены проверки UI на 1920×1080, 1440×1080 и 2560×1080:
покупка и недоступная покупка, полный каталог, смена категорий, склад,
найм, русский/английский, модальные окна и возврат ввода.
Дополнительно пройдены игровые проверки выкладки, кассы, уборки, охраны,
зарплат, маршрута через дверь, обновления кошелька и движения NPC.
Отдельная проверка посылает события перетаскивания через настоящий EventSystem:
один жест даёт один шаг, до пятого жеста товары не переносятся.

Повторение: открыть сохранённую `Game` в Edit Mode →
`Retail Empire/UI/Open isolated UI preview` → Play →
`Retail Empire/UI/Validate redesigned UI in sandbox`.
Для проверки реального магазина сначала использовать
`Retail Empire/Shop/Load player layout read only`.
Отчёты и кадры: `Library/ShopUiQA`; игровые отчёты: `Library/ShopGameplayQA`.
Вернуться через Stop и `Retail Empire/Shop/Return to Game`.

## Ограничения

Обновлены игровые окна из предоставленных скриншотов. Отдельная сцена главного
меню и обучающие диалоги не переоформлялись. Мобильная/портретная компоновка
не проверялась. Проверка выполнена в редакторе, отдельная Windows-сборка не создавалась.
Прежние предупреждения сторонних/старых компонентов проекта не относятся к
новой теме и не были скрыты.

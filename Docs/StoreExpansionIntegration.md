# Интеграция товаров и оборудования

В основной Unity-проект перенесены 48 товаров последней волны и 16 новых видов торгового оборудования. Пакет `Assets/Resources/StoreAssortment/Expansion.asset` содержит 144 уникальные товарные позиции и 20 видов оборудования с учётом предыдущих волн. Багет использует существующий товарный ID: новая модель заменяет его внешний вид, сохраняя прежние цены и совместимость сохранений.

## Как использовать в игре

1. В Store → Equipment купите оборудование, получите доставку и поместите его на склад.
2. В Construction выберите оборудование из склада, разместите на свободной площади; существующее оборудование можно выбирать, переносить и поворачивать.
3. В Store → Products закажите подходящие товары, получите их на склад.
4. Назначьте товар установленному оборудованию и пополните запас через существующую систему выкладки; работники используют те же точки обслуживания.
5. Посетители берут выставленный товар, оплачивают его и уходят. Планировка и остатки сохраняются существующей системой сохранения.

Новые виды: пристенный стеллаж, двусторонний ряд, торцевой стеллаж, промокорзина, хлебная витрина, овощной прилавок, холодильная витрина, морозильник, панель с крючками, стойка уборочного инвентаря, стеллаж зоотоваров, садовый стеллаж, игрушки, канцтовары, товары для дома и детские товары. Названия в интерфейсе английские.

## Правила выкладки

У каждого оборудования задан список совместимых товаров. Каждое место ограничивает размер модели по свободному пространству. Метлы и швабры подвешиваются за верхнюю точку на специальных крючках; нижние полки стойки используются для остальных средств уборки. Вместимость нового оборудования определяется совместимыми местами выкладки. Старые стеллажи сохраняют прежнюю вместимость, чтобы не терять остатки из сохранений.

Сохраняется текущая модель магазина: один назначенный вид товара на один установленный стеллаж. Смешанный ассортимент по отдельным ярусам не добавлялся. Новое оборудование доступно для покупки и строительства; существующая планировка игрока автоматически не заменяется.

## Проверки

- Play Mode в отдельной копии проекта: PASS для 144 позиций по цепочке UI заказа → оплата → доставка/груз → склад → выкладка/корзина → сохранение.
- 20 видов оборудования: покупка, доставка, размещение в четырёх поворотах, восстановление планировки и остатков, покупка реальным игровым посетителем с оплатой один раз.
- Все 346 разрешённых сочетаний новых стеллажей и товаров: выкладка до полной вместимости, габариты моделей, точки доступа работника.
- После переноса в основной проект: 2146 файлов Unity проверены на ссылки; отсутствующих ссылок нет. В пакете 144 уникальных ID товаров и 20 уникальных ID оборудования.
- Сохранения игрока не использовались тестами. Основная сцена не копировалась из тестового проекта.

Подробные результаты текущего запуска: `Library/StoreExpansionIntegration/play.txt`, `details.txt`, `references.json`. Список перенесённых файлов: `installed_files.txt`; резервные копии заменённых файлов: `Before/`. Эта папка Library локальная и может быть очищена Unity.

Если Play Mode был включён во время переноса, перезапустите его после окончания импорта Unity: каталоги подключают пакет при загрузке.

# Bakery & desserts

Шесть товаров по согласованному превью: Croissant, Doughnut, Muffin, Pretzel, Cupcake, Cake slice. Это настоящие модели Blender с префабами Unity и иконками, отрендеренными из этих префабов.

## Модели

- `ArtSource/Bakery/<key>/<key>.blend` — отдельный редактируемый исходник каждого товара.
- `ArtSource/Bakery/Concept.png` — утверждённый визуальный ориентир.
- `ArtSource/Bakery/Models.json` — размеры, число треугольников и SHA-256 экспортов.
- `ArtSource/Bakery/Definitions.json` — имена, хранение, цены, вес и объём.
- `Assets/Art/Bakery` — FBX, префабы, общий материал и палитра.
- `Assets/Resources/StoreAssortment/Bakery/Products` — игровые данные товаров.
- `Docs/BakeryExpansion/Models.png` — обзор окончательных моделей в Unity.

У каждого товара одна сетка и один материал. Крупные грани остаются плоскими, силуэт смягчён небольшими геометрическими фасками. Фототекстур, шума, мелкой надписанной упаковки и высокополигонального сглаживания нет. Генератор проверяет положительный объём замкнутых частей, чтобы поверхности не смотрели внутрь. Единственная открытая декоративная поверхность — накладка глазури пончика.

## Работа в игре

Товары видны в `Store → Products`. Одна упаковка содержит 10 единиц.

| Товар | Заказ 10 шт. | Продажа 1 шт. | Вес 1 шт. |
| --- | --- | --- | --- |
| Croissant | $40 | $7 | 0.10 кг |
| Doughnut | $30 | $6 | 0.09 кг |
| Muffin | $40 | $7 | 0.12 кг |
| Pretzel | $30 | $6 | 0.12 кг |
| Cupcake | $50 | $9 | 0.12 кг |
| Cake slice | $60 | $11 | 0.18 кг |

Путь товара: оплаченный заказ → поставщик Bakery → погрузка в выбранный автомобиль → разгрузка на склад → существующий Bakery rack → покупатель → оплата на кассе. Водитель использует те же оплаченные заказы и поставщиков. Новые объекты не выдаются бесплатно в стартовый набор.

Все шесть товаров имеют тип хранения `Bakery`; отдельная категория полок не требуется. Прежний хлебный стеллаж принимает их через действующие правила. Одна полка, как и раньше, содержит один вид товара. `ShelfProductSlot` вписывает каждую модель в доступное место на полке.

## Каталог и сохранения

Шесть стабильных ID `product_<key>` добавлены в конец существующего `StoreAssortmentPack`. Прежние 48 товаров и 4 витрины сохраняют порядок, ссылки и GUID. Состав пакета теперь — 54 товара и 4 витрины; остальные старые товары сцены продолжают работать.

Общий редакторский импорт товаров принимает каталог моделей и данных явно, поэтому новый набор использует ту же логику цены, веса и создания префаба. Повторная сборка первой волны больше не удаляет товары из следующих наборов: каталоги объединяются по ID с сохранением порядка.

Основные игровые сцены и пользовательские сохранения не перезаписываются. Для иконок добавлен мягкий боковой свет: плоские грани в отдельной preview-сцене больше не проваливаются в полностью чёрную тень. Это изменение редакторского рендера иконок, а не освещения игры.

## Проверка

Нативный Unity 2022.3.62f3, изолированная копия проекта и копия Game без компонентов записи пользовательских сохранений.

- Повторная проверка всей расширенной линейки из 54 товаров: карточки магазина, недостаточный баланс, оплата, выдача у правильного поставщика, вес/объём, разгрузка однократно, сохранение склада, выкладка, видимые модели и границы слотов.
- Проверка четырёх витрин предыдущей волны: установка во всех поворотах, восстановление планировки/остатков и реальные покупки NPC.
- Для каждого из шести новых товаров: начало ручной выкладки, отмена без расхода, повторная выкладка с пятью действиями, восстановление остатка из штатных данных сохранения.
- Для каждого товара настоящий NPC доходит до хлебного стеллажа, выбирает товар, встаёт в очередь, платит ровно один раз и уходит.
- Иконки и итоговое превью просмотрены визуально; исправлена ориентация поверхностей круассана/кренделя и расположение украшения торта.

Отчёты — `Docs/BakeryExpansion/build.txt`, `play.txt`, `bakery.txt`, `assortment.txt`, `inputs.sha256`. Отдельная сборка приложения не запускалась.

## Повторная генерация

`Scripts/Blender/BakeryDesigns.py --project <путь>` создаёт палитру и данные (нужен Pillow).

`Blender --background --factory-startup --python Scripts/Blender/BuildBakeryModels.py -- --project <путь>` создаёт шесть моделей. `--only <key>` выбирает один товар. Существующий `.blend` не перезаписывается: прежде нужно сохранить авторские изменения и отложить предыдущий файл.

В изолированном Unity: `BakeryExpansionBatch.BuildAndPlay`. Для проверки без повторного импорта: `BakeryExpansionPlay.Run`. Установка: `Scripts/InstallBakeryExpansion.ps1`; `-ValidateOnly` сначала сверяет отчёты, хеши, разрешённые пути и прежние GUID. При замене общего каталога сохраняется резервная копия.

# Образцы нового направления для покупателей

Три отдельных варианта для оценки внешнего вида, а не массовая замена действующих 50 покупателей.
Основа геометрии — существующий в проекте набор `mini characters`, созданный Kenney (www.kenney.nl). Это переработанные проектные ассеты, не заявленные как полностью новые модели с нуля.

Сохранены авторские формы лиц, волос, обуви и их градиентное UV-затенение. Удалены походные очки, рюкзаки, ремни и сумки, изменены одежда и обувь, опущены руки, восстановлен закрытый стык между торсом и брюками. Сердитое выражение заменено улыбкой.

Исходники: `ArtSource/Shoppers/StyleStudies/V3/Study_01/Study_01.blend` … `Study_03/Study_03.blend`.
В каждый `.blend` упакована палитра; добавлены редактируемый скелет из 14 костей и действия Idle, Walk, Browse.
Манифест рядом с исходниками содержит источники и SHA256 файлов.
Генератор `Scripts/Blender/BuildShopperStyleStudy.py` по умолчанию не перезаписывает готовый образец. `--replace-studies` разрешает заменить только эти три пробных файла.

У образцов своя исходная поза скелета, поэтому нужен собственный `Study.controller`, а не старые клипы от процедурных Shopper_01–50. При масштабировании направления на 50 вариантов общий контроллер необходимо собрать на основе нового скелета.

`UnityStudy.png` — реальные импортированные модели. `InGameStudy.png` — три образца, выставленные для обзора возле магазина в изолированной копии Game при игровом освещении. Это выставочный кадр, не утверждение о массовой расстановке или проверке торгового AI.
`UnityMotion.png` показывает фазы анимации. Проверяются импорт, материал, валидность скелетов и движение всех трёх состояний у всех трёх моделей. Компонент записи сохранения игрока в тестовой сцене отсутствует.

`Assets/Resources/Shoppers/Roster.asset` и действующие 50 моделей не изменяются этим просмотром.

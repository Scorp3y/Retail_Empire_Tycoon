Each category folder includes six separate GLB files, a self-contained Python script, Models.blend, preview, validation and audit JSON, and reviewed iteration files.

19 original helper functions and the base palette/bevel settings were compared structurally to the previous ready-meal category and are unchanged. All exports have identity transforms, centred XY origins and bottom at Z=0. At most four materials per model, no image textures. GeometryPigment is a vertex-colour material.

Runtime tested: installed Blender 5.2.3 LTS. Blender 4.x runtime was not installed/tested. The scripts reuse the existing compatible API. Files deliberately contain Z-up geometry; Unity import must convert axes and preserve vertex colours and alpha materials. The Unity procurement catalogue was not modified in this modelling task.
